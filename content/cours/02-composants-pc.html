Socket CPU

Rôle : Accueille le processeur et impose la compatibilité de plateforme.

À vérifier : Même génération de CPU ne suffit pas : il faut vérifier le socket, le chipset et parfois la version du BIOS/UEFI.

Symptôme typique : CPU incompatible : écran noir, POST bloqué, ventilateurs qui tournent sans affichage.

VRM

Rôle : Stabilise la tension envoyée au processeur.

À vérifier : Sur une machine puissante, des VRM faibles peuvent provoquer chauffe, baisse de fréquence ou instabilité.

Symptôme typique : Redémarrages en charge, throttling, ventilateurs bruyants autour du socket.

Slots RAM

Rôle : Accueillent les barrettes mémoire, idéalement en dual channel.

À vérifier : Les générations DDR ne sont pas interchangeables. On installe les barrettes dans les slots recommandés par le manuel.

Symptôme typique : PC qui ne démarre pas, bips POST, écrans bleus ou lenteurs si la RAM manque.

PCIe x16

Rôle : Connecte la carte graphique ou une carte d'extension rapide.

À vérifier : La taille physique x16 ne garantit pas toujours 16 lignes câblées. Le manuel de la carte mère tranche.

Symptôme typique : GPU non détecté, performances réduites, affichage branché sur la mauvaise sortie.

Slot M.2

Rôle : Reçoit un SSD compact, en SATA ou NVMe selon la carte.

À vérifier : M.2 est un format physique. NVMe est un protocole sur PCIe : les deux notions sont différentes.

Symptôme typique : SSD absent du BIOS, disque lent, mauvais emplacement ou mode SATA/NVMe confondu.

Ports SATA

Rôle : Connectent HDD, SSD SATA et lecteurs optiques.

À vérifier : Ils nécessitent deux câbles : données vers la carte mère et alimentation depuis le bloc PSU.

Symptôme typique : Disque non détecté : vérifier câble SATA, alimentation, port, puis gestion des disques.

ATX 24 pins

Rôle : Alimentation principale de la carte mère.

À vérifier : Sans ce connecteur bien enclenché, la carte ne reçoit pas correctement ses tensions principales.

Symptôme typique : Aucun démarrage, voyants absents ou comportement instable.

EPS CPU 8 pins

Rôle : Alimente directement l'étage CPU.

À vérifier : À ne pas confondre avec certains câbles PCIe GPU, même si les formes semblent proches.

Symptôme typique : Ventilateurs qui tournent, mais pas de POST ou extinction immédiate.

Chipset

Rôle : Gère une partie des échanges entre stockage, USB, PCIe et périphériques.

À vérifier : Il complète le CPU : certaines lignes et fonctions passent par lui, avec de la bande passante partagée.

Symptôme typique : Ports ou périphériques absents, limites de lignes PCIe, fonctions indisponibles.

Backplate I/O

Rôle : Expose les ports vers l'extérieur : USB, réseau, audio, vidéo.

À vérifier : Pour diagnostiquer un périphérique, on commence souvent par changer de port ou tester en façade/arrière.

Symptôme typique : USB instable, réseau absent, mauvais port vidéo utilisé.

Vue d'ensemble de l'architecture

Un poste de travail est composé de plusieurs éléments interdépendants :

Composant Rôle
Boîtier Protège et organise les composants
Carte mère Relie et fait communiquer tous les composants
Processeur (CPU) Effectue les calculs
Mémoire vive (RAM) Stocke temporairement les données en cours d'utilisation
Stockage Conserve les données (SSD, HDD)
Carte graphique (GPU) Gère l'affichage
Alimentation (PSU) Fournit l'énergie électrique

Chaque composant a un rôle précis. Une panne ou une limite de performance vient souvent de l'un d'eux.

La carte mère

La carte mère détermine :

  • le type de processeur utilisable (socket)
  • le type et la quantité de RAM
  • les possibilités d'évolution (slots PCIe, ports SATA, M.2)

Elle centralise toutes les connexions internes.

Le processeur (CPU)

Le processeur (CPU) est le composant central du PC. Il exécute les instructions des programmes et coordonne les autres composants.

Sans CPU fonctionnel, le PC ne démarre pas.

Symptômes courants

  • PC lent malgré un SSD → CPU saturé
  • Ventilateurs bruyants → TDP élevé ou refroidissement insuffisant
  • Redémarrages en charge → problème thermique ou d'alimentation
  • Écran noir au démarrage → CPU incompatible ou sans GPU intégré
Info

À retenir : le socket conditionne toute la plateforme. Le choix du CPU dépend toujours de l'usage, jamais uniquement du prix.

La mémoire vive (RAM)

La RAM est l'espace de travail du processeur : elle stocke temporairement les données en cours d'utilisation.

La RAM est volatile : son contenu est perdu à l'arrêt du PC.

La mémoire RAM — malekal.com

Principe DDR (Double Data Rate)

La RAM moderne effectue deux transferts par cycle d'horloge (front montant + front descendant).

  • DDR5-6000 → fréquence réelle : 3000 MHz
  • Chaque génération (DDR3, DDR4, DDR5) est physiquement incompatible avec les autres

Single Channel vs Dual Channel

Mode Bus Bande passante
Single channel 64 bits Performances de base
Dual channel 2 × 64 bits Bande passante doublée
Bon réflexe

Toujours installer la RAM en paires identiques pour activer le dual channel.

Repères capacité

Capacité Usage
8 Go Usage léger
16 Go Usage standard (recommandé)
32 Go+ Usages avancés (vidéo, dev, virtualisation)

La latence (CAS Latency)

Latence (ns) = CL / fréquence réelle (MHz) × 1000

Fréquence élevée ≠ latence faible — le compromis fréquence/CL compte.

Symptômes liés à la RAM

  • PC lent avec disque très actif → manque de RAM (swap actif)
  • Applications qui se ferment → saturation mémoire
  • Écran bleu aléatoire → barrette défectueuse
  • PC ne démarre pas → RAM incompatible ou mal installée
Info

À retenir : la RAM est l'espace de travail du CPU. Dual channel améliore fortement les performances. Une RAM inadaptée provoque lenteurs et instabilités.

L'alimentation (PSU)

L'alimentation (PSU) convertit le courant secteur en tensions stables pour tous les composants.

Une alimentation de mauvaise qualité peut provoquer instabilités, redémarrages et pannes matérielles.

Puissance et rendement

Paramètre Rôle
Puissance (W) Doit couvrir tous les composants + marge de stabilité
Certification 80 PLUS Bronze → Titanium — plus le rendement est élevé, moins ça chauffe

Types de modularité

Type Câbles
Non modulaire Tous fixes
Semi-modulaire Câbles principaux fixes
Modulaire Tous amovibles — facilite le montage et la maintenance

Connecteurs principaux

  • 24 pins — carte mère
  • 4/8 pins CPU — processeur
  • PCIe — carte graphique
  • SATA — stockage

Symptômes liés à l'alimentation

  • PC qui ne démarre pas
  • Redémarrages aléatoires
  • Ventilateurs qui s'arrêtent brutalement
  • Instabilité lors de fortes charges
Info

À retenir : l'alimentation est un composant critique souvent sous-estimé. La puissance doit être adaptée + une marge est nécessaire. La certification 80 PLUS est un bon indicateur de qualité.

Les lignes PCI Express (PCIe)

Le PCI Express (PCIe) est le bus de communication haut débit entre le CPU et les composants rapides : carte graphique, SSD NVMe, cartes d'extension.

PCI Express — Wikipédia

Lignes (lanes) et slots

Slot Lignes Usage courant
x1 1 Carte réseau, USB, son
x4 4 SSD NVMe, carte RAID
x8 8 GPU en configuration dual
x16 16 Carte graphique principale

Évolution des versions

Version Débit par ligne Débit x16
PCIe 3.0 ~1 Go/s ~15,75 Go/s
PCIe 4.0 ~2 Go/s ~31,5 Go/s
PCIe 5.0 ~4 Go/s ~63 Go/s

La rétrocompatibilité est assurée (une carte PCIe 3.0 fonctionne dans un slot PCIe 4.0).

Points d'attention

  • Un slot x16 peut être câblé en x8 → performances réduites si GPU dessus
  • Les lignes PCIe proviennent du CPU (rapides) ou du chipset (partagées)
  • La taille physique du slot ≠ nombre réel de lignes actives
Info

À retenir : plus de lignes = plus de bande passante. Le format du slot ne garantit pas toujours le câblage réel.

Les composants d'un PC

Objectif

Construire une configuration PC cohérente, adaptée à un usage donné, en justifiant le choix de chaque composant.

Contexte

Vous êtes technicien support. Un utilisateur vous demande conseil pour l'achat d'un PC (tour seule).

Outils

Utiliser au moins un configurateur :

  • PCPartPicker
  • LDLC
  • Matériel.net
  • Cybertek

Cas à choisir

Cas Usage Budget
Cas 1 — PC bureautique Bureautique / web / multimédia léger ~600 €
Cas 2 — PC gaming Jeux vidéo récents ~1400 €

Contraintes techniques

La configuration doit inclure : boîtier, carte mère, CPU, RAM, stockage, alimentation.

Points de vigilance :

  • compatibilité CPU / carte mère
  • type et quantité de RAM
  • puissance et qualité de l'alimentation
  • lignes PCIe si nécessaire

Rendu attendu

Un document Markdown dans votre HedgeDoc, contenant :

  • le besoin choisi
  • la liste des composants avec prix
  • le budget total
  • la justification de chaque composant
Attention

Le raisonnement compte plus que la configuration finale. Justifiez chaque choix en lien avec le besoin.
